# New Chat Bootstrap — LifeSim

Use this when starting work in a fresh chat.

1. Open https://github.com/Ye-Shwethway/creators-universe-lifesim and verify default branch and latest commit.
2. Read AGENTS.md, README.md, docs/ARCHITECTURE.md, docs/ROADMAP.md, docs/CURRENT_STATE.md, docs/ASSET_POLICY.md.
3. Inspect current scene/scripts, export_presets.cfg and CI workflows; check open PRs/issues and actual latest Actions status.
4. Identify the current milestone, incomplete operations and any Creator decisions; do not assume successful builds without logs.
5. Preserve public/private boundaries. Do not copy private Universe images, names, detailed canonical profiles or paid models into this public repository without explicit approval.
6. Compose the smallest needed task, propose actions when destructive/irreversible, execute, test, update checkpoint, verify remote state.
7. Summarize what changed, latest commit, evidence, remaining risks and exact next step.

## Project essentials
Godot 4 + GDScript; mobile-first; browser-first playability with native Android APK export; Redmi K70 (12 GB) is target test device. The user wants a Sims-like hybrid life simulator centered on Darian, with physical training progression and eventually autonomous NPC life. Current public MVP uses generic placeholder art until Creator authorizes and supplies suitable assets.
