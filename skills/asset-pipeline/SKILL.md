# asset-pipeline

**Scope:** Public/free redistributable models; private asset protection; provenance; import.

## Instructions
Require asset manifest with origin, explicit license, redistribution permission, attribution and hash. Keep generic public demo self-contained. Private character files remain private; avoid uploading even to CI, logs or public bundles. Assets inside distributables are extractable. Validate glTF mesh/rig/morph formats and polygon/texture budgets.

## Mandatory verification
No asset accepted until source/license/identity/provenance/size and import verified; public build scanning and no private strings/paths/art approval.
