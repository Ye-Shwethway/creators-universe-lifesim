# LifeSim Domain Skills

Project-local, task-routed instruction set. These do **not** copy or replace DEDAL Core. Every skill is a specific engineering contract, not merely a topic page.

Entry: read `skills/registry.yaml`; select primary and at most three dependent skills. Read chosen `SKILL.md` documents **before** editing code. Follow acceptance tests, record citations/evidence, and update docs/CURRENT_STATE.md.

Priority: Creator decisions → observed repository/runtime state → project contracts → selected skill instructions → external references. A web reference informs engineering but does not itself prove the deployed build.

Skill identities remain stable; changes require corresponding registry and checkpoint update.
